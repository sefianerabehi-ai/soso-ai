# 🌟 SoSo AI | رفيقك الذكي اليومي

تطبيق ذكاء اصطناعي متكامل يحاكي أشهر وأقوى النماذج العالمية مثل **Gemini** و **ChatGPT** و **Claude**، مصمم خصيصاً ليكون رفيقك اليومي المخلص الذي يجيب على استفساراتك بدقة متناهية، مع إمكانية فريدة لتحليل وفهم الصور وحل المسائل واستخراج النصوص منها.

---

## ✨ المميزات الرئيسية

1. **دقة متناهية وشخصية رفيق يومي**:
   - إجابات دقيقة ومنظمة بنقاط وعناوين واضحة.
   - رفيق مشجع يساعدك في تنظيم يومك، زيادة إنتاجيتك، وحل المشكلات اليومية.

2. **ذكاء بصري خارق (Vision & Multimodal)**:
   - إمكانية رفع الصور بالسحب والإفلات (Drag & Drop)، أو اللصق المباشر من الحافظة (Ctrl+V)، أو عبر زر الإرفاق (📎).
   - استخراج وتفريغ النصوص من الصور بدقة عالية (OCR).
   - حل المسائل الرياضية والعلمية وشرح المخططات والتصاميم البرمجية خطوة بخطوة.

3. **واجهة استخدام عصرية ومريحة (UI/UX)**:
   - تصميم حديث داكن (Dark Mode) ونهاري (Light Mode) مستوحى من Gemini و ChatGPT.
   - دعم كامل للغة العربية (RTL) وتنسيق فائق الجمال للخطوط (Google Cairo & Inter).
   - تنسيق نصوص Markdown متقدم (جداول، قوائم، اقتباسات).
   - تلوين الأكواد البرمجية (Syntax Highlighting) مع زر مخصص لنسخ الكود بضغطة زر.
   - دعم الصيغ والمعادلات الرياضية المعقدة عبر (LaTeX / KaTeX).

4. **ميزات صوتية متقدمة**:
   - **قراءة صوتية (TTS)**: استمع إلى إجابات SoSo AI بصوت ناطق واضح.
   - **كتابة صوتية (STT)**: تحدث مباشرة عبر الميكروفون وسيقوم سوسو بكتابة ما تقوله والرد عليك.

5. **إدارة المحادثات والسجلات**:
   - حفظ سجل المحادثات تلقائياً محلياً على جهازك.
   - إنشاء محادثات جديدة، تعديل العناوين، والبحث السريع في المحادثات السابقة.
   - تصدير المحادثة كاملة كملف Markdown بضغطة زر.

6. **مرونة كاملة في المحركات**:
   - يدعم محركات **Google Gemini 2.5 Flash / 1.5 Pro** مجاناً وفائقة السرعة.
   - يدعم أيضاً محركات **OpenAI** و **Groq** و **Ollama** المحلية وغيرها عبر إعدادات التطبيق.

## 🚀 طريقة التشغيل السريعة

### الطريقة الأولى: بنقرة زر (Windows)
فقط قم بالنقر مرتين على الملف:
```
run.bat
```
سيقوم بفتح الخادم وتشغيل واجهة المتصفح تلقائياً على الرابط `http://localhost:8000`.

---

### الطريقة الثانية: عبر سطر الأوامر (PowerShell / Terminal)
1. الدخول إلى مجلد المشروع:
```powershell
cd "C:\Users\LAPTA\.gemini\antigravity\scratch\soso_ai"
```

2. تشغيل التطبيق عبر بايثون البيئة الافتراضية:
```powershell
.\.venv\Scripts\python.exe run.py
```

---

## 🔑 تفعيل مفتاح الذكاء الاصطناعي (API Key)

1. بعد فتح التطبيق في المتصفح، اضغط على زر **الإعدادات ⚙️** في القائمة الجانبية أو أعلى الشاشة.
2. احصل على مفتاح مجاني بضغطة زر من: [Google AI Studio](https://aistudio.google.com/app/apikey).
3. الصق المفتاح في خانة **Google Gemini API Key** واضغط **حفظ الإعدادات**.
4. سيبدأ **SoSo AI** بالرد عليك فوراً وتحليل صورك بأقصى سرعة ودقة!
